# Angelo Averion — Portfolio

A responsive React and Vite portfolio with light and dark themes.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run `npm run build`.

## Update content

- Edit `src/data/projects.js` to add or change project cards. Empty `githubUrl` and `demoUrl` values hide those links. Set `image` to an asset in `public/assets/projects` for source artwork; cards without an image use labeled concept visuals. The bus schedule art is an illustration.
- Edit `src/data/skills.js`, `experience.js`, and `certifications.js` for those sections.
- Update personal copy and contact links in `src/sections.jsx`. The LinkedIn item is intentionally marked "Link to add" until you provide a profile URL.
- Replace `public/assets/angelo-portrait.webp` and `public/resume/Angelo_Averion_CV.pdf` to update the photo or downloadable CV.

The experience section describes academic and independent practice. It does not claim a completed internship or professional role.
